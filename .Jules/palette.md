## 2025-08-02 - Table-Based Component Accessibility Retrofitting
**Learning:** When retrofitting legacy HTML tables used as action grids (like interactive calculator buttons), we can avoid invasive HTML restructuring by dynamically injecting role="button", tabindex="0", and appropriate ARIA labels on `DOMContentLoaded`. However, to support both keyboard-focused activation (using Enter or Space) and global physical keyboard handlers, the local keyboard listeners must use `stopPropagation` on matching keys. This prevents event bubbling from triggering both the focused cell's action and the global shortcut listener, which would otherwise result in duplicate keypress registrations.
**Action:** Always stop event propagation in cell-specific keyboard listeners when global keyboard shortcuts are active on the same window, or check the target/focus to prevent double-firing.
