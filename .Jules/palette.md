## 2025-07-18 - Retrofitting Keyboard Accessibility to Table Cells
**Learning:** Retrofitting legacy table-based grid layouts (`<td>`) for standard calculator buttons with keyboard accessibility is an effective UX win. Adding `tabindex="0"`, `role="button"`, and screen-reader friendly `aria-label`s dynamically via JS minimizes code modification (keeping changes under 50 lines) while satisfying WCAG success criteria. Element-level `keydown` events must intercept `Enter` and `Space` using `preventDefault()` and `stopPropagation()` to block default scroll behaviors and conflicting global key handlers.
**Action:** Always intercept element-specific `keydown` triggers on customized components and isolate keyboard propagation to avoid multiple execution paths. Combine CSS `:focus-visible` with `position: relative` and `z-index: 1` to ensure focus rings are never clipped by adjacent grid/table cell borders.
