## 2025-07-31 - Retrofitting Table-based UI with Keyboard Accessibility
**Learning:** Retrofitting legacy table-based button UI elements with custom focus indicators and keydown listeners provides a zero-refactor solution to standard keyboard and screen reader accessibility compliance. Outlining `td` elements correctly using `position: relative` and `z-index: 1` prevents outlines from being partially clipped by adjacent cell borders in dense CSS grid/table layouts.
**Action:** When retrofitting legacy tabular grid inputs, use a centralized DOMContentLoaded script to dynamically attach `tabindex="0"`, `role="button"`, and standard localized ARIA labels alongside keyboard and stopPropagation event listeners, while utilizing z-indexed custom `:focus-visible` styles to avoid border collision visually.
