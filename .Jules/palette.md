## 2025-05-14 - Accessible Table-based Calculator
**Learning:** Retrofitting accessibility (role, tabindex, listeners) to legacy table-based UI elements like <td> using a centralized DOMContentLoaded script is an efficient UX pattern that avoids heavy HTML refactoring while ensuring keyboard and screen reader support. Using e.stopPropagation() in focused button listeners is crucial to prevent "double trigger" events when global keyboard shortcuts (like Enter for equals) are also present.
**Action:** Always include e.stopPropagation() when adding keyboard listeners to custom buttons if global keyboard shortcuts are also implemented.
