## 2024-05-24 - Retrofitting Accessibility to Table-based UI
**Learning:** Retrofitting accessibility (role, tabindex, labels) to legacy table-based UI elements using a centralized `DOMContentLoaded` script is an efficient UX pattern that avoids heavy HTML refactoring while ensuring keyboard and screen reader support.
**Action:** Use a script-based injection for accessibility attributes when working with legacy or repetitive structures to ensure consistency and minimize HTML bloat.
