## 2024-11-08 - Retrofitting Accessibility & Tactile Keyboard Feedback to Table Calculator
**Learning:** Table cell (`<td>`) based buttons lack inherent keyboard focusability and ARIA semantics; retrofitting `tabindex="0"`, `role="button"`, and mapping `Enter`/`Space` listeners along with physical keyboard shortcuts (`0-9`, operators, `Enter`/`Escape`) immediately transforms a mouse-only widget into a fully accessible calculator. Ensuring custom focus rings have `position: relative` and `z-index: 1` prevents focus indicators from being clipped by table cell borders.
**Action:** When working on legacy table-based interfaces, use a DOMContentLoaded enhancement loop to dynamically add keyboard focus and ARIA attributes without requiring destructive HTML restructuring, and style `:focus-visible` with elevated z-index for crisp focus visibility.
