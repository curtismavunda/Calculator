## 2026-10-28 - Retrofitting Accessibility to Table-Based UI Elements
**Learning:** Legacy table-based UIs (`<td>` buttons) lack keyboard focusability and screen reader semantics by default. Adding `tabindex="0"`, `role="button"`, descriptive `aria-label` attributes, and `keydown` event listeners for `Enter` and `Space` enables full accessibility without restructuring HTML tables. Additionally, `td:focus-visible` with `position: relative` and `z-index: 1` ensures focus outlines are not clipped by adjacent table borders.
**Action:** When adding keyboard focus and ARIA roles to table cells or custom non-button elements, ensure both `Enter` and `Space` key handlers are wired with `event.preventDefault()` and set `:focus-visible` outline styles with proper stacking context (`z-index: 1`).
