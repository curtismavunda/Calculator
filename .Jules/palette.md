## 2025-05-14 - [Retrofitting Keyboard Accessibility to Table-based UI]
**Learning:** When retrofitting `tabindex="0"` and keyboard listeners to legacy table-based interactive elements (like `<td>` in a calculator), it's crucial to use `event.stopPropagation()` in the button-specific listeners if global keyboard shortcuts are also implemented. Without it, a focused button press might trigger both its specific action and a global action (e.g., Enter triggering both a digit press and the equals function). Also, ensure that internal handlers (e.g., `digitBtnPressed`) are robust enough to handle various input types (strings from keyboard events vs elements/values from onclick).
**Action:** Always implement a centralized DOM initialization script for consistent attribute injection and use explicit event propagation control to prevent double-triggering in hybrid interaction models (mouse + keyboard + global shortcuts).
