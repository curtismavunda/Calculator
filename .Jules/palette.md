## 2026-10-31 - Retrofitting Keyboard Accessibility onto Table-Based Buttons
**Learning:** Legacy table-based calculator buttons built with `<td>` elements lack native keyboard focus, screen reader semantics, and key activation. Adding `tabindex="0"`, `role="button"`, and mapping arithmetic symbols to descriptive `aria-label` attributes (`multiply`, `divide`, etc.) via DOMContentLoaded script creates full accessibility without altering the table layout or existing styles. Custom focus rings using `:focus-visible` with `position: relative` and `z-index: 1` ensure outlines are clearly visible above adjacent cell borders.
**Action:** When retrofitting legacy table or non-interactive element UIs, use a centralized DOMContentLoaded setup for `role`, `tabindex`, and keyboard listeners (Enter/Space), and use `:focus-visible` with elevated z-index to maintain visual clarity without affecting mouse interactions.
