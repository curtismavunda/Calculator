## 2025-05-14 - Retrofitting Accessibility to Legacy Tables
**Learning:** Retrofitting accessibility (role, tabindex, listeners) to legacy table-based UI elements using a centralized script is an efficient UX pattern that ensures keyboard and screen reader support without heavy HTML refactoring.
**Action:** Use a DOMContentLoaded script to map ARIA labels and add keyboard listeners to interactive non-semantic elements in legacy codebases.
