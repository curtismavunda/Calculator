## 2025-07-01 - Active State Feedback for Toggle/Operator Buttons
**Learning:** Adding visual active state indicators (`.active-operator`) alongside screen-reader state attributes (`aria-pressed`) to operator buttons gives users immediate clarity on pending calculator operations.
**Action:** When creating toggle or selectable state buttons, ensure state is updated both visually (via CSS classes) and programmatically for assistive tech (`aria-pressed`).
