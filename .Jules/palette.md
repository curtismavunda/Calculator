## 2025-05-15 - Interactive Table-Based Calculator Accessibility
**Learning:** When retrofitting accessibility onto a table-based UI where `<td>` elements act as buttons, dynamic injection of `role="button"`, `tabindex="0"`, and `aria-label` via a JS loop is cleaner than manual HTML edits. Implementing both global keyboard shortcuts and local `keydown` handlers for focused elements requires `event.stopPropagation()` on the local handler to prevent double-triggering (e.g., Enter key firing both the button click and the global listener).
**Action:** Use a unified DOMContentLoaded listener to inject ARIA attributes and handle keyboard navigation/interactions in legacy web projects. Always use `stopPropagation` on element-specific keyboard listeners if a global listener is also present.
